# CoNLL Editor

Aplikasi web sederhana untuk membantu validasi label pada file CoNLL. Upload file CoNLL (.conll), tandai tiap token dengan label yang sesuai, dan simpan hasilnya kembali dalam format CoNLL.

## Prasyarat

- Node.js dan npm

## Cara menjalankan aplikasi ini

1. Buka terminal dan navigasikan ke direktori proyek.
2. Instal dependency yang diperlukan:
   ```bash
   npm install
   ```
3. Setelah selesai menginstal, jalankan aplikasi dengan perintah berikut:
   ```bash
   npm run dev
   ```
4. Aplikasi akan berjalan di http://localhost:5173
5. Gunakan aplikasi untuk mengunggah file .conll, mengecek hasil anotasi, dan menyimpan hasilnya dalam format CoNLL.
6. Untuk menghentikan aplikasi, kembali ke terminal dan tekan `Ctrl + C`.
